# HW1: Accessible Data-Grid

Sortable, filterable, paginated data grid built with Vite, React 19 and TypeScript (WCAG 2.2 AA).

## Commands
- `npm run dev` start the dev server
- `npm run lint` oxlint with jsx-a11y rules
- `npx vitest run` unit tests
- `npm run build` type-check and production build

## Docs
- `project-rules.md` rules given to the AI
- `TASK_DECOMPOSITION.md` work breakdown
- `AI_FAILURE_AUDIT.md` verified AI failures
